# 📊 Impacto y monitoreo

EcoTask utiliza monitoreo externo para comprobar la disponibilidad del servicio.

## Indicadores

| Indicador | Objetivo |
|---|---|
| Disponibilidad | ≥ 95% |
| Tiempo de respuesta | Medible |
| Tareas registradas | Incrementar |
| Reconocimientos | Incrementar |
| Cambios validados | 100% mediante GitHub Actions |

## Monitoreo

La disponibilidad del servicio será monitoreada mediante UptimeRobot.

## Evidencia

Se agregará una captura del monitor activo mostrando:

- Estado del servicio.
- Disponibilidad.
- Tiempo de respuesta.

## Resultado esperado

Contar con evidencia cuantificable de que el servicio se encuentra disponible y que el proyecto puede ser monitoreado.
