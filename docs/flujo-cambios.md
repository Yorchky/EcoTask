# 🔄 Flujo de cambios de EcoTask

## 1. Propuesta

Todo cambio comienza con una propuesta que describe:

- Qué se quiere modificar.
- Por qué es necesario.
- Qué parte del proyecto afecta.

## 2. Rama de trabajo

El integrante crea una rama:

git checkout -b feature/nombre-del-cambio

## 3. Desarrollo

Se realizan los cambios y las pruebas necesarias.

## 4. Pull Request

Se crea un Pull Request hacia main.

El Pull Request debe incluir:

- Descripción del cambio.
- Evidencia de pruebas.
- Archivos modificados.

## 5. Revisión

Otro integrante revisa el código.

## 6. Aprobación

Si el cambio cumple los requisitos, se aprueba.

## 7. Integración

El cambio se integra a main.

## 8. Validación automática

GitHub Actions ejecuta automáticamente la validación del proyecto.

## Flujo

Propuesta
↓
Rama
↓
Desarrollo
↓
Pull Request
↓
Revisión
↓
Aprobación
↓
Merge
↓
GitHub Actions
↓
Validación
