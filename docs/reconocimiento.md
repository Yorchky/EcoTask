# 💚 Cultura de reconocimiento

EcoTask utiliza un espacio de reconocimiento para destacar las contribuciones de los integrantes.

## Canal

Discord:

#kudos

## Ejemplos

### Reconocimiento 1

> Reconozco a [Nombre] por completar el diseño del prototipo y mejorar la experiencia de usuario.

### Reconocimiento 2

> Reconozco a [Nombre] por configurar la API y solucionar los errores de conexión.

### Reconocimiento 3

> Reconozco a [Nombre] por documentar el proyecto y organizar las evidencias.

## Objetivo

Crear una cultura donde las contribuciones del equipo sean visibles y valoradas.

## Evidencia

Se presentarán capturas del canal de Discord donde cada integrante publique al menos un reconocimiento genuino.
